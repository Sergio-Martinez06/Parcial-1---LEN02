s de # Parcial-1---LEN02
Repositorio para subir el ejercicio práctico (en parejas) del primer parcial de Lenguajes de Programación grupo LEN02


Descripción del problema:

La universidad busca digitalizar el control de un parqueadero de aproximadamente 30 cupos el cual es frecuentado por 3 tipos de usuarios: Estudiantes, visitantes y docentes. 
Cada uno paga una tarifa diferentes reglas de acceso. El programa debe simular la entrada de los vehículos al parqueadero durante el día, calcular los cobros, aplicar los descuentos y llevar seguimiento de las estadísticas en cuestión basándose en los temas vistos hasta ahora.
